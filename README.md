# Rangabazar.com Website Template

A responsive, static storefront template for Rangabazar.com, built with HTML, CSS, and vanilla JavaScript.

## Files

- `index.html` — the website homepage and styling/scripts.
- `assets/rangabazar-logo.png` — the supplied Rangabazar logo.
- `.nojekyll` — tells GitHub Pages to serve the site without Jekyll processing.

## Preview locally

Open `index.html` in a browser. Internet access is needed for the Google Fonts and Unsplash images used by the template.

## Publish with GitHub Pages

1. Create a GitHub repository (for example, `rangabazar-website`).
2. Upload **all files and folders in this project** to the repository's root. Keep `index.html` at the root and keep the `assets` folder beside it.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. The published URL will appear on the Pages settings screen.

## Before launching a real store

- The product names, prices, photos, ratings, and order/cart actions are demonstration content. Replace them with real product information.
- The cart currently shows a toast and stores a simple count in the browser; it does not process orders or payments.
- The newsletter form is a front-end demo and does not save email addresses.
- Update contact details, seller email, policies, and delivery claims to match your actual business.
- Product and hero photos are loaded from Unsplash, and fonts from Google Fonts, so those assets require an internet connection.
